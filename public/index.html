    How it works

    D(k)[i][j] = min( D(k−1)[i][j], D(k−1)[i][k] + D(k−1)[k][j] )
    • Subproblem. D(k)[i][j] is the cheapest cost from i to j using only cities 1…k as stops in between.
    • Base case. D(0) is the direct road cost matrix, 0 on the diagonal and ∞ where there is no road.
    • Route recovery. A next-hop matrix stores the first city to visit, so any route can be rebuilt by following it.
    • Negative cycle. If any D[i][i] < 0 at the end, some costs fall without limit and have no cheapest value.
